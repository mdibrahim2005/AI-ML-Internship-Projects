\# AI \& ML Internship Projects



This repository contains my completed projects developed during my AI \& ML internship.



\## Projects Included



\### 1. AI-Powered Resume Ranker



An AI-based web application that analyzes resumes and compares them with job requirements.



\#### Features

\- Upload PDF resumes

\- Extract resume text automatically

\- Analyze candidate skills

\- Calculate resume-job match score

\- Display skill matching results

\- Provide relevant resume analysis

\- Flask-based web interface

\- Resume history and session support



\#### Technologies Used

\- Python

\- Flask

\- Pandas

\- NumPy

\- PDFMiner / PDFPlumber

\- HTML

\- CSS

\- Machine Learning / NLP concepts

\### 2. News Article Classification – Fake or Real



A machine learning web application that classifies news articles as Fake or Real.



\#### Features

\- Text preprocessing

\- Machine learning classification

\- Fake/Real prediction

\- Flask web interface



\#### Technologies Used

\- Flask

\- Pandas

\- NumPy

\- Scikit-learn

\- TF-IDF

\- Machine Learning

\- HTML

\- CSS
